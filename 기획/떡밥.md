## 레테 — 숨기기와 강해지기
| 떡밥 | 상태 |
|---|---|
| 카운터 스펠. 아직 아무도 모른다. 약한 자리를 알면 세 번에 한 번이 열 번에 아홉 번이 된다 | 미회수 |
| 부호가 넷에서 여섯으로 늘어 갈래가 넓어졌다. 그래서 **영창의 마디가 바뀌었다** — 들을 수 있는 사람이 있다 | 미회수 |
| 여덟 걸음(모인 점을 멀리 두기)은 이미 절반쯤 와 있다. 떠나 있는 겹을 붙들 무엇은 책이 다루지 않는다 | 미회수 |
| 방에서는 더 연습할 수 없다(창유리가 울었다). 개인 수련실은 고위 귀족이 선점한다 | 미회수 |
| 필사본 반납 — 귀퉁이가 끈적해졌고, 더 보려면 필사 허가가 필요하다 | 미회수 |
| "쉴드도 제대로 못 쓰는 반푼이"가 고학년까지 돈다. 조원에게 옮아가면 괜찮다고 말할 수 없다 | 진행 |
| 아르누의 연구회를 거절했다. 살롱은 파벌 지도다 | 미회수 |
| 남동생이 **내년에** 온다. 한 해 조용히 지낸 값이 그 아이에게 청구될 수 있다 | 미회수 |
| 제 얼굴을 자기가 볼 수 없다. 웃는 것을 진심으로 모른다 | 미회수 |
## 알리시아 — 위장과 자리
| 떡밥 | 상태 |
|---|---|
| 본명과 에스페리아 왕가. 공간 마법을 쓰는 순간 발각된다 | 미회수 |
| 위장 영지의 세부를 모른다("아랫강"). 딸이 여섯인 자작가라면 수도에 이름이 돌았을 것 — 레테가 멈춘 셈 | 미회수 |
| 클로에 드마레가 에스페란토 가문을 캐물었다 | 미회수 |
| 자작가라는 이름으로는 뭉치는 자리가 만들어지지 않는다 | 진행 |
| 집에서 이름으로 불린 적이 없다. 다들 "막내"라고 불렀다 | 미회수 |
## 두 사람 사이
| 떡밥 | 상태 |
|---|---|
| 이름 — 알리시아가 두 번 청했고 두 번 다 "어렵습니다". 약칭 "레테"는 아무에게도 주지 않았다 | 진행 |
| 틀린 미들네임 — 레테가 편지 서명으로 **이슈타카르**를 놓아 알리시아가 알게 되었다. 왜 여섯 번을 고쳐 주지 않았는지는 아직 묻지 않았다 | 진행 |
| 레테의 웃음을 알리시아가 알려 주기로 했다 | 진행 |
| 알리시아가 말하지 않은 "다른 생각" | 미회수 |
| 알리시아가 문 안의 소리를 의자 끄는 소리로 넘겼다 | 미회수 |
## 조와 편성
| 떡밥 | 상태 |
|---|---|
| 저녁 자리에서 여섯이 실제로 묶이는가 — 레테는 제가 연결고리라는 것이 긴장이다 | 진행 |
| 여섯이 다 모였다 — 남은 것은 서로를 보고 정하는 일뿐이다 | 진행 |
| 세라피나가 기억해 둔 "셋이서 하자"던 조 — 이름은 아무도 모른다 | 미회수 |
| 마르고와 뤼카가 다른 조로 갔다("폐를 끼쳤다") | 진행 |
| 세라피나가 아홉 번을 보류한 것을 레테는 모른다 | 미회수 |
| 사람이 많은 자리에서 되는 사람이 조에 필요하다(세라피나의 자각) | 미회수 |
| 아무도 부르지 않은 자들끼리 묶이는 자리 | 미회수 |
