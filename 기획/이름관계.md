# 누가 누구의 이름을 아는가
> 초반 원고의 핵심 규칙: 확실히 아는 사이가 아니면 반드시 통성명 장면을 거친다. 통성명 전에는 서로를 이름으로 부르지 않고, 외형·머리색·가문 소문으로만 가리킨다.

## 현황 (챕터4 2회 시점)
| 아는 쪽 → 아는 대상 | 어떻게 | 비고 |
|---|---|---|
| 알리시아 → 레테 | Ch0 무도회 통성명, Ch1 호명으로 두 모습을 이음 | 미들네임은 여전히 "이슈카타르" |
| 레테 → 알리시아 | Ch0 무도회 통성명 | 정확히 기억. 같은 기숙사인 줄은 모른다 |
| 레테 ↔ 테세브리아 | Ch1 입학식 옆자리 | 레테는 "아스트레테 벨페리아"까지만 밝혔다 |
| 테세브리아 → 레테 | 가문도 안다 | 벨페리아 백작을 한 번 뵌 적 있음 |
| 알리시아 → 에드몽 뤼바르, 티보 다르크 | Ch0 면접 | |
| 레테 → 아델린 코르뱅 | Ch0 면접 | |
| 알리시아 → 에티엔 모르네, 클로에 드마레, 티에리 발몽 | Ch0 무도회 | 상호 |
| 레테 → 에티엔·클로에·티에리 | 모름 | 아직 만나지 않음 |
| 조원 5인 상호 | 챕터1 실습 첫 시간 통성명 | 레테·알리시아·세라피나·뤼카·마르고 |
| 세라피나 ↔ 알리시아 | 서로 이름 + 반말 | 챕터4 시점. 열엿새 사이에 그렇게 되었다 |
| 세라피나 → 조원 | 이름으로 부르라 청함 | 레테는 아직 이름으로 부르지 않는다 |
| 마르고 → 조원 | "마르고로 불러도 됩니다" | |
| 삼조 5인 ↔ 사조 5인 | 챕터1 첫 대련 전 통성명 | 오귀스트 빌마르, 이자보 크레메르 등 |
| 이자보 → 레테 | 기본 마법학 뒷줄에서 보았다 | 쉴드가 떨리는 것을 직접 봤다 |
| 사조 5인 → 뮈리엘 | 통성명 없음 | 삼조가 부르는 소리로 이름만 들었다 |
| 레테 ↔ 테오 이스카리온 | 챕터4 무도회에서 통성명 | 테오는 그 전에 명부에서 레테의 이름을 보았다 |
| 사조 5인 ↔ 뤼시앵 모르바크 | 교수가 이름을 밝혔다 | 학생 쪽은 아직 이름을 말하지 않았다 |
| 클로에 → 레테 | 가문 소문으로만 | "벨페리아의 영애". 이름은 모른다 |

## 지키는 것
- 레테는 공식 자리에서도 미들네임을 말하지 않는다. "아스트레테 벨페리아"까지가 보통이다. 전체 이름을 아는 사람은 무도회의 알리시아(틀리게)와 서류뿐이다.
- 알리시아가 챕터4에서 "아스트레테"로 부르게 해 달라 청했고, 레테는 "어렵습니다"라고만 답했다. 거절도 승낙도 아니며, 알리시아는 나중에 다시 묻겠다고 했다.
- 레테는 "레테"라는 약칭을 아직 아무에게도 내주지 않았다. 남들에게는 "아스트레테 이슈타카르 벨페리아" 또는 "벨페리아 영애"다.
- 알리시아의 이름은 위장 신분의 이름이다. 본명을 아는 인물은 아직 없다.
- 챕터1에서 알리시아가 "아스트레테 이슈카타르 벨페리아"라고 소리 내어 말했고, 레테는 고쳐 주지 않았다. 다른 조원들도 들었다.
- 알리시아가 레테의 이름을 정확히 고쳐 부르게 되는 순간은 두 사람이 한 걸음 가까워지는 표지로 쓴다. (`방향.md`)
