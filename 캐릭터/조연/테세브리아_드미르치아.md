# 테세브리아 드 미르치아

- 외형: 백금발 · 녹안 / 155cm의 작은 키. 빈틈없이 올린 머리, 곧은 등, 움직이지 않는 손. 단단한 눈빛. 화려하지 않은 방식으로 값비싼 옷
- 말투: 낮고 짧다. 우아한 예의. 농인지 아닌지 분간이 어렵다
- 계열: 마법사
- 재능: 강 — 여러 계열을 두루 쓴다 / 약 — [미정]
- 습득 마법 [초안]: **보라색 번개**(마디 넷이 고르게 끊긴 뒤 하나가 짧게 붙는다. 갈라지지 않고 한 줄기로 굵으며, 지나간 자리의 모래가 **검게 굳는다** — 벨페리아의 흰빛 번개와 다른 것이다) / **끌어들이는 구체**(그쪽으로 발이 미끄러진다) / **메테오** / **나무 피우기**
- **밀어내는 것 [초안]**: 접근하면 그냥 밀려난다. 무엇이 오는지 보이지 않고 소리도 없으며 영창도 들리지 않는다. 세라피나는 발이 땅에 붙은 채로 다섯 걸음 밀려났다 — 밀려나는 것보다 **중심을 잃는 것**이 문제다. 구조를 모르므로 파훼법이 없고, 세라피나는 작년 겨울부터 답을 찾지 못했다
  - 닿는 것인지 아닌지도 모른다. 그러므로 아퀼레이아도 지나가게 할 수 있는지 알지 못한다
